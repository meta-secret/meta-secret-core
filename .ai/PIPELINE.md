# Pipeline reference

The canonical stage order, outputs, conditions and release gates are defined in [WORKFLOW.md](WORKFLOW.md). Use its Stage 3.5 constraint gate, Stage 7 security review, Stage 8 code review, Stage 10 coverage, Stage 11 tests, Stage 11.5 final UI E2E, Stage 12 user approval and Stage 13 release. Do not use legacy eight-stage numbering.
